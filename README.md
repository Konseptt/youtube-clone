# 🎥 Streamline - YouTube Clone

Streamline is a minimalist video streaming platform inspired by YouTube. It replicates and simplifies core YouTube functionalities, focusing on user experience and a streamlined design.

## 🌟 Features

- 📺 **Video Streaming**: Seamless video playback with essential controls.
- 🔍 **Search**: Quickly find videos by title or keyword.
- 🎨 **Responsive Design**: Works across devices with a clean, minimal interface.
- 📚 **Playlist Management**: Organize and manage your favorite videos.

## 🛠️ Tech Stack

- **Frontend**: React, CSS, HTML
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **API**: Custom-built RESTful API

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Konseptt/youtube-clone.git
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Set up environment variables**:
   Create a `.env` file in the root directory with the following:
   ```plaintext
   MONGO_URI=<your-mongo-db-uri>
   API_KEY=<your-api-key>
   ```
4. **Run the development server**:
   ```bash
   npm run dev
   ```
